# Question Types

## Multiple Choice
Use for concept distinctions, factual understanding, and short application scenarios.

Requirements:
- one best answer
- plausible distractors
- explanation after the answer

## True / False
Use for precise definitions and common misconceptions. Avoid ambiguity.

## Fill in the Blank
Use for terminology, formulas, and key phrases.

## Short Answer
Ask the student to explain a concept in their own words.

## Essay
Use for comparison, argument, cause/effect, and critical interpretation.

## Case / Application
Use realistic scenarios to test transfer of knowledge rather than verbatim recall.
