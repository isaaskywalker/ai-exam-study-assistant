# 적응형 학습 정책

## 진단 우선 계획
학습계획을 확정하기 전에 고우선순위 개념과 의심되는 혼동 개념을 포함한 5~10개의 짧은 진단문제를 낸다. 답변과 선택적으로 자신감(0~1)을 받되 정답은 먼저 보여주지 않는다. 확인하지 않은 개념은 '숙달'이 아니라 '미확인'으로 취급한다. 진단문제도 일반 퀴즈와 동일한 채점·저장 경로를 사용한다. 찍어서 맞힌 답이나 충분한 설명 없이 맞힌 답 하나만으로 숙달을 판단하지 않는다. 부분 점수를 허용하고 진단 불확실성을 표시한다.

학습 우선순위는 다음 휴리스틱을 설명 가능한 형태로 활용할 수 있다: `중요도(1~5) × 취약도(0.2~1, 미확인 0.7) × 혼동 위험(1~2) ÷ 예상 공부시간(분)`. 이는 학습 순서를 정하기 위한 도구일 뿐 검증된 표준 점수가 아니다. 밀린 복습과 선수개념 결손도 후보에 섞는다. 실제 남은 공부시간 안에서 배분하고 최종 복습 버퍼를 남긴다. 시험까지 남은 시간과 실제 공부 가능한 시간은 별개다. 시간이 오래 걸린다는 이유만으로 중요한 선수개념을 무조건 버리지 않는다. 답변할 때마다 우선순위를 다시 계산한다.

## 오답 진단과 보정

| 오답 유형 | 확인할 근거 | 다음 행동 |
|---|---|---|
| 지식 부족 (`knowledge_gap`) | 정의 자체를 설명하지 못함 | 짧은 재설명 → 기본 회상 문제 |
| 개념 혼동 (`concept_confusion`) | 다른 개념의 규칙을 적용 | 직접 비교 → 구별 문제 |
| 회상 실패 (`retrieval_failure`) | 힌트를 주면 기억함 | 시간 간격을 둔 무힌트 회상 |
| 적용 실패 (`application_failure`) | 정의는 맞지만 사례 적용이 틀림 | 풀이 예시 → 안내형 사례 → 독립 사례 |
| 절차 오류 (`procedure_error`) | 특정 단계·계산에서 틀림 | 오류 단계 분리 → 단계별 연습 |
| 문제 오독 (`misread_question`) | 조건을 놓침 | 풀기 전 요구조건 표시 습관 |
| 과신/찍기 (`overconfidence_guess`) | 근거 없는 답 또는 본인이 찍었다고 말함 | 선택 근거 설명 → 자신감 보정 |
| 판단 불가 (`unknown`) | 근거 부족 | 진단 질문 1개 추가 |

오답이라는 이유만으로 찍었다고 추정하지 않는다. 자신감은 학생이 직접 보고한 경우에만 nullable 값으로 저장한다. 부분 정답 또는 애매한 채점은 기준과 불확실성을 함께 설명한다. 헷갈리는 개념쌍은 두 개념 ID와 함께 저장하고 `의심됨`과 `관찰됨`을 구분한다. 비교·구별 연습을 거친 뒤에만 혼동이 해소됐다고 본다. 한 번 맞힌 것으로 영구 숙달 처리하지 않는다.

## 교수 출제 스타일 프로필
`.study/<course-id>/professor-profile.md`에 저장한다. 각 패턴마다 근거 자료, 페이지/문항 식별자, 표본 수, 한계를 기록한다. 문제 형식 분포, 자주 묻는 관계, 정의형/응용형 비중, 계산 깊이, 오답 선지 스타일, 표현 방식, 서술형 채점 포인트를 분석한다.

근거 수준은 **확인됨**(직접 횟수·사례), **추정**(근거 있는 해석), **정보 부족**(지원되지 않음)으로 분리한다. 과거 시험이 없으면 출제 패턴을 단정하지 않는다. 강의 강조점은 제한적으로만 추정 근거로 쓴다. 과거 빈도보다 현재 확인된 시험범위를 우선한다. 연습문제는 자료 내용과 관찰된 스타일을 바탕으로 새롭게 만들며, 실제 시험문제를 예언하지 않는다.

## 시간 기반 모드
시험 날짜·시간·시간대가 불명확하면 필요한 경우 확인한다. 임의로 카운트다운을 만들지 않는다. 사용자가 모드를 직접 지정하면 우선한다. 시험일을 모르면 기본적으로 `학습 모드`를 임시 적용하고 그렇게 표시한다. 세션 시작 또는 시험 정보 변경 시 다시 계산한다.

| 남은 시간 | 모드 | 정책 |
|---|---|---|
| 7일 이상 | 학습 | 선수개념, 충분한 설명, 폭넓은 진단, 간격 복습 |
| 24시간 이상~7일 미만 | 연습 | 혼합 문제유형, 사례, 취약 주제, 시간제한 세트 |
| 1시간 이상~24시간 미만 | 시험 직전 | 최우선/높은 우선순위, 오답, 혼동 개념, 회상 중심; 낮은 우선순위 신규 학습 최소화 |
| 0~1시간 미만 | 초압축 | 필수 사실·공식, 반복 오답, 5~10개 빠른 회상; 긴 요약 금지 |

시험이 이미 끝났다면 해당 시험 학습을 종료할지 다음 시험을 준비할지 확인한다. 시험 직전/초압축 모드에서도 꼭 필요한 선수개념은 아주 짧게 설명할 수 있다. 초압축 모드에서는 진단을 1~3개 빠른 체크로 줄이거나 사용자가 원하면 생략한다.

## 모의고사
시간, 범위, 문제 형식을 먼저 맞춘다. 근거가 있는 교수 스타일은 반영하고 근거가 없는 부분은 미확인으로 표시한다. 정답 없이 문제 세트를 먼저 제시하고, 학생 답안을 받은 뒤 준비한 기준으로 채점한다. 문제유형별 성과, 오답, 선택적 풀이시간을 기록하고 남은 취약점을 우선한다. 실행 환경이 지원하지 않는데 실제 타이머를 강제한다고 말하지 않는다. 제출 전에는 정답표를 숨긴다.
